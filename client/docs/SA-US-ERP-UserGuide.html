SA-US ERP User Guide

Complete guide for setting up and using SA-US ERP — Business Management System

Version 2.7.0  ·  SA Ultimate Solutions  ·  November 2026

📋 Introduction

SA-US ERP is a business management system that helps small and medium businesses manage customers, sales, invoices, and records from one place. It runs on your own computer — no internet required after installation.

What you can do with SA-US ERP

  • Add and manage customers and contacts
  • Create and send invoices
  • Record payments and track balances
  • Manage products and services
  • View sales reports and summaries

How it works

The system has two parts that work together:

  1. Server — This is the engine that stores all your data. It runs quietly in the background on one computer (usually the main office computer).
  2. Client — This is the app you use every day. It connects to the server to show your data. Multiple people can run the client on different computers at the same time.
Note: All data is stored in a built-in database (SQLite) — no extra software required.

💿 Installation

Installation only needs to be done once, on the main computer that will act as the server.

What you need before you start

  • A Windows computer (Windows 10 or newer)
  • The installer file: SA-US-ERP-Setup.exe
  • About 200 MB of free disk space

Steps

  1. Find the file SA-US-ERP-Setup.exe and double-click it to open.
  2. A setup window will appear. Click Next to begin.
  3. Choose where to install. The default location (C:\SA-US-ERP) is recommended. Click Next.
  4. The installer copies all files automatically. This takes about 1–2 minutes.
  5. When it says Installation complete, click Finish.

After installation, you will find two new items in your Start Menu:

  • SA-US ERP Server — starts the server (must be running before anyone can log in)
  • SA-US ERP Client — the app you use to work with your data
Note: You do not need administrator rights to run the program after installation. The database is created automatically the first time the server starts.

🖥️ First-Time Server Setup

The server must be started before anyone can use the system. Do this on the main office computer.

Starting the server

  1. Open the Start Menu and click SA-US ERP Server.
  2. A small black window will appear — this is the server running. Do not close it.
  3. You will see: Uvicorn running on http://0.0.0.0:8000 — this means it is ready.
First run: The server automatically creates the database file (sa_us_erp.db) in the installation folder. No action needed.

Creating the first admin account

  1. Start the Client app (see Client Setup below).
  2. On the login screen, click Register or Create Account.
  3. Enter a username, email address, and a strong password.
  4. The first account created is automatically given admin (administrator) access.

Keeping the server running

  • The server must stay open while people are using the system.
  • If you close the server window, no one will be able to log in until you start it again.
  • For an office that uses the system all day, start the server in the morning and leave it running.

💻 Client Setup

The client is the app that staff use to access the system. It can be installed on one or many computers.

Installing the client on additional computers

  1. Copy the file SA_US_ERP_Client.exe from the installation folder (C:\SA-US-ERP\client\) to the other computer.
  2. Double-click it to run — no installation wizard needed.
  3. Create a shortcut on the desktop for easy access.

Connecting to the server

The first time you open the client, it will ask for the Server Address. This is the IP address of the computer where the server is running.

  • Same computer: http://localhost:8000
  • Over a network: http://192.168.1.10:8000 (use the server's actual IP)
How to find the server IP address: On the server computer, open Command Prompt and type ipconfig. Look for the line that says IPv4 Address — for example: 192.168.1.10.

Once the address is saved, the client will remember it. You will not need to enter it again.

🔑 Logging In and Dashboard

Logging in

  1. Open the SA-US ERP Client.
  2. Enter your username and password.
  3. Click Login.

If you see "Cannot connect to server", check that the server is running on the main computer.

The Dashboard

After logging in, the dashboard shows a summary of your business at a glance:

AreaWhat it shows
CustomersTotal number of active customers
InvoicesRecent invoices and their status
PaymentsPayments received this month
OutstandingAmount owed to you by customers

Navigating the app

The menu on the left side lets you move between sections:

  • Customers — view, add, and edit customer records
  • Invoices — create and manage invoices
  • Payments — record payments received
  • Products/Services — manage what you sell
  • Reports — view summaries and export data
  • Settings — admin options (admin users only)
Tip: Always click Logout when leaving the computer to protect your data.

📅 Day-to-Day Use

Adding a Customer

  1. Click Customers in the left menu.
  2. Click + New Customer.
  3. Fill in the customer's name, phone number, email, and address.
  4. Click Save.

Creating an Invoice

  1. Click Invoices in the left menu.
  2. Click + New Invoice.
  3. Select the customer from the dropdown list.
  4. Add items or services — enter the quantity and price for each.
  5. The total is calculated automatically.
  6. Click Save to save, or Save & Send to email it to the customer.

Recording a Payment

When a customer pays:

  1. Click Payments in the left menu.
  2. Click + New Payment.
  3. Select the customer and the invoice being paid.
  4. Enter the amount received and the date.
  5. Click Save.

The invoice status will update automatically to Paid or Partially Paid.

Editing or Deleting Records

  • To edit: click on the record to open it, then click Edit.
  • To delete: open the record and click Delete. You will be asked to confirm.

Viewing Reports

  1. Click Reports in the left menu.
  2. Choose the type of report (Sales Summary, Outstanding Invoices, Payment History, etc.).
  3. Select a date range.
  4. Click Generate.
  5. Print the report or export it as a file.

🌐 Network Setup for Multiple Users

SA-US ERP supports 3–4 users working at the same time over a local office network. No internet is required — all computers must be on the same Wi-Fi or wired network.

ComputerWhat to installWhat to run
Main office computer (server)Full installer (SA-US-ERP-Setup.exe)Server + Client
Other staff computersClient only (SA_US_ERP_Client.exe)Client only

Step-by-step for a 3-computer office

  1. Install and start the server on the main computer (see Installation and Server Setup sections).
  2. Find the server computer's IP address: open Command Prompt, type ipconfig, look for IPv4 Address.
  3. On each staff computer, copy SA_US_ERP_Client.exe and open it.
  4. When asked for the server address, enter: http://<server IP>:8000 — for example: http://192.168.1.10:8000
  5. Each staff member logs in with their own account.

User Accounts

  • The admin can create accounts for each staff member from Settings → Users → Add User.
  • Each user gets their own username and password.
  • Admin users can see all settings; regular users can only access day-to-day functions.
Important: The server computer must be turned on and the server must be running before other staff can log in.

🔧 Troubleshooting

"Cannot connect to server"

Cause: The server is not running, or the address is wrong.

  1. Go to the main computer and check that the Server window is open. If not, start it from the Start Menu.
  2. Check the server address in the client settings. It should be http://<IP>:8000.
  3. Make sure both computers are on the same network (same Wi-Fi or same router).

"Wrong username or password"

  • Double-check the username and password. Passwords are case-sensitive.
  • If forgotten, an admin user can reset it from Settings → Users.

The server window closes by itself

This can happen if the computer goes to sleep. Fix: disable sleep mode on the server computer.

Go to: Settings → Power & Sleep → Sleep → Never

An invoice or record is missing

  • Check that you are logged into the correct account.
  • Use the search bar to look for the record by name or number.
  • Check if a filter is applied (e.g. only showing unpaid invoices) — clear the filter to see all records.

The program does not open

  • Right-click the app and choose Run as administrator.
  • If it still does not open, restart the computer and try again.
  • Check that your antivirus is not blocking it — add an exception for the ERP folder if needed.

Backing Up Your Data

Your data is stored in a single file: sa_us_erp.db inside C:\SA-US-ERP\server\

  • To back up: copy sa_us_erp.db to a USB drive or another location. Do this at least once a week.
  • To restore: stop the server, replace the sa_us_erp.db file with your backup copy, then restart the server.
